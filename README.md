# Rock · Paper · Scissors (1v1)

A two-player, hot-seat Rock-Paper-Scissors game built with plain HTML, CSS, and JavaScript.

## How to play
1. Open `index.html` in a browser.
2. Enter both player names and click **Start Game**.
3. Each round, Player 1 picks, then Player 2 picks (pass the device so picks stay secret).
4. Rock beats scissors, scissors beats paper, paper beats rock. Same pick = tie.
5. First player to **3 round wins** takes the match.

## Files
- `index.html` – page structure
- `style.css` – colors, layout, animations
- `script.js` – game logic (`Player` class, `getRoundResult()`, `render()`)
